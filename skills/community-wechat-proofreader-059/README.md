# 公众号文章校对助手

检查公众号文章的错别字、标点、语句、数字日期、事实清单、敏感信息和标题一致性。

## 适用场景

- 公众号发布前通读校对
- 活动稿数字核对
- 政策稿敏感数据检查

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得把无法核实的表述直接改为肯定
- 不得虚构校对依据
- 不得忽略重大事实和隐私风险
