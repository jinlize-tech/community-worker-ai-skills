# 社区活动照片优化助手

提供社区活动照片的真实本地优化或可执行修图指导，支持曝光、白平衡、裁切、降噪、锐化和公众号尺寸适配。

## 适用场景

- 活动照片偏暗
- 手机照片色彩偏黄
- 批量压缩并统一尺寸

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

WorkBuddy ViewImage 已验证可读取照片；本地Python/Pillow已验证可实际输出JPEG、PNG、WEBP优化图。WorkBuddy客户运行时是否允许执行脚本需以后台能力为准；不支持时提供修图参数。

## 边界

- 不得声称已生成实际图片，除非文件真实存在
- 不得换脸、虚构现场、增加或删除人员
- 不得覆盖原图
- 不得擅自修改政府标识、横幅和活动名称
