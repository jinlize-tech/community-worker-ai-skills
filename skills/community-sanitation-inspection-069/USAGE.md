# 社区环境卫生巡查助手 使用说明

## 直接调用

```text
请使用「社区环境卫生巡查助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 巡查范围和日期
- 发现问题及位置
- 严重程度
- 责任单位（如有）
- 整改与复查状态

## 标准输出

- 巡查总表
- 重点问题清单
- 整改责任表
- 重复问题观察
- 复查记录模板

## 示例

11月1日巡查A、B、C三个片区。A区2处垃圾散落，B区垃圾点满溢并连续3天出现，C区1处地面油污已清理。请整理并排优先级。

## 隐私提醒

使用点位编号和问题编号；照片中的人脸、门牌和车辆信息应脱敏。
