# 社区环境卫生巡查助手

把分区巡查记录整理为问题清单、风险排序、整改责任与复查闭环。

- 产品编号：JLZ-COM-SK-069
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区巡查员、网格员、物业保洁管理人员
- 发布方式：公开源码

## 核心能力

- 分区巡查表
- 问题分级
- 整改责任建议
- 重复问题识别
- 复查记录

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不凭单张图片认定长期问题
- 不公开保洁人员姓名和处罚信息
- 不代替环境卫生主管部门考核

本产品不替代正式审批或专业判断，不调用外部收费API。
