# 公众号标题优化助手

根据文章内容生成至少5个真实、准确、不同风格的标题，并检查标题与正文一致性。

## 适用场景

- 活动推文标题不满意
- 政策文章的居民化标题
- 人物故事标题提炼

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得制造震惊、恐吓、虚假紧迫感
- 不得把未发生的结果写进标题
- 不得用无法验证的数据或绝对化承诺
