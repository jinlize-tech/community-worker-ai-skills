# 社区活动新闻稿助手

根据已发生活动记录生成正式新闻稿和公众号版本，整理时间、地点、参与情况与照片说明。

## 适用场景

- 活动结束后上报新闻稿
- 社区公众号活动报道
- 街道材料汇总

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得伪造新闻事实、领导讲话、人数和成效
- 不得把计划写成报道
- 不得使用未授权照片和采访原话
