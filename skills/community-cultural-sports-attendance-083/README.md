# 社区文体活动签到统计助手

整理报名、签到、候补、缺席和现场补录，输出准确的参与统计与异常清单。

- 产品编号：JLZ-COM-SK-083
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区文体活动负责人、活动执行人员、志愿者
- 发布方式：公开源码

## 核心能力

- 报名与签到核对
- 重复记录识别
- 缺席与候补统计
- 现场补录
- 活动摘要

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不虚增参与人数
- 不公开完整个人信息
- 代签或缺签需标注待核实

本产品不替代正式审批或专业判断，不调用外部收费API。
