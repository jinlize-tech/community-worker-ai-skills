# 公众号文章润色助手

在不改变事实的前提下润色公众号文章，优化结构、逻辑、冗余和阅读节奏，并支持语气切换。

## 适用场景

- 活动稿内容生硬
- 政策稿过长
- 需要把内部汇报改为公众号文风

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得未经允许改变事实和观点
- 不得通过润色制造成效或承诺
- 不得删除必要风险提示和来源
