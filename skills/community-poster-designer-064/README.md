# 社区宣传海报设计助手

为社区活动、志愿服务、政策和节日主题提供海报文案层级、配色、构图和多尺寸适配方案。

## 适用场景

- 社区活动海报设计
- 志愿招募海报
- 政策宣传展板

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

具备视觉读取和设计说明能力；默认不调用生成式收费图像API。需要实际图片时，仅使用当前环境明确提供的免费能力，否则输出可复制设计提示词。

## 边界

- 不得伪造政府机构标识、官方徽章或合作单位Logo
- 不得虚构活动信息
- 没有图像生成能力时不得声称生成成品
