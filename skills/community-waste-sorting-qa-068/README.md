# 垃圾分类宣传与居民问答助手

基于用户提供的当地分类规则，生成居民问答、易错点说明和多渠道宣传文案。

- 产品编号：JLZ-COM-SK-068
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区宣传人员、垃圾分类指导员、物业人员
- 发布方式：公开源码

## 核心能力

- 规则分层整理
- 高频问答
- 误区纠偏
- 宣传短句
- 来源待确认标记

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不编造当地分类目录、投放时间和处罚标准
- 不把一般经验写成官方规定
- 政策更新时要求复核来源

本产品不替代正式审批或专业判断，不调用外部收费API。
