# 垃圾分类宣传与居民问答助手 使用说明

## 直接调用

```text
请使用「垃圾分类宣传与居民问答助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 适用地区与分类规则来源
- 居民高频问题
- 投放时间或点位（如有）
- 目标渠道
- 必须保留的原文

## 标准输出

- 居民问答
- 分类易错点
- 群通知版
- 宣传短句
- 待核实事项

## 示例

依据社区提供的分类指南：电池中的充电电池属有害垃圾，普通干电池按当地现行要求投放；投放点为东门和北门，时间7:00-9:00。居民常问外卖盒如何投放。请做问答。

## 隐私提醒

不展示居民姓名、门牌号和具体投放监控画面。
