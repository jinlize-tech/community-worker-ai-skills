# 公众号发布前检查助手

对公众号文章进行标题、正文、图片、版权、肖像、儿童隐私、联系方式、政策来源和结构检查，形成发布前清单。

## 适用场景

- 公众号发布前最终审核
- 活动照片公开前隐私检查
- 政策文章上线前核对

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得把未核实内容标记为可发布
- 不得替代法务、宣传或主管部门审核
- 不得忽略政策和版权风险
