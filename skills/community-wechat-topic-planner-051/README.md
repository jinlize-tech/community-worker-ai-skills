# 公众号选题策划助手

围绕社区公众号定位、居民关注和活动政策，生成周月度选题规划、系列策划与素材清单。

## 适用场景

- 制定下月社区公众号内容计划
- 围绕传统节日策划系列内容
- 把活动台账转为公众号选题

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得虚构社区活动、政策热点和居民需求
- 不得以保证阅读量或涨粉作为选题依据
- 不得把未经确认的节日活动写成已定计划
