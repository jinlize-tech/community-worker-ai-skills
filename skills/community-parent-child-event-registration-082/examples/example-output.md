# 输出结构示例

## 任务摘要

已按「亲子活动报名与通知助手」处理合成输入。以下结构用于演示，不添加输入中不存在的事实。

## 事实与口径

| 项目 | 内容 | 状态 |
|---|---|---|
| 输入事项 | 已按产品任务整理 | 已提供 |
| 关键数量与日期 | 保留原值，不推测未提供数据 | 已核对/待确认 |
| 责任主体 | 仅在用户明确提供时写入 | 待确认 |

## 核心成果

- 报名表字段
- 报名通知
- 确认通知
- 候补通知
- 活动前提醒

## 风险与边界

- 不公开报名者名单和联系方式
- 不制造虚假名额紧张
- 改期时明确原报名是否有效

## 待确认事项

- 输入材料是否完整。
- 政策、时间、地点、责任主体和数字是否经过有权人员复核。
- 对外发布前是否完成隐私与授权检查。
