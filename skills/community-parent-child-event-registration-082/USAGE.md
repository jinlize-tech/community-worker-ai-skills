# 亲子活动报名与通知助手 使用说明

## 直接调用

```text
请使用「亲子活动报名与通知助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 活动时间地点
- 名额与年龄范围
- 报名截止时间
- 监护人要求
- 改期或取消规则

## 标准输出

- 报名表字段
- 报名通知
- 确认通知
- 候补通知
- 活动前提醒

## 示例

11月10日亲子手工活动，20组，儿童5-8岁，需1名监护人陪同，11月7日截止。请写报名和确认通知。

## 隐私提醒

报名只收集监护人必要联系方式、儿童年龄区间和活动安全信息。
