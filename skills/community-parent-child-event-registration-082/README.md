# 亲子活动报名与通知助手

生成亲子活动报名表字段、确认通知、候补规则和隐私最小化说明。

- 产品编号：JLZ-COM-SK-082
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区活动组织者、亲子活动负责人、居民服务人员
- 发布方式：公开源码

## 核心能力

- 报名字段设计
- 确认与候补通知
- 名额边界
- 活动前提醒
- 监护人授权提示

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不公开报名者名单和联系方式
- 不制造虚假名额紧张
- 改期时明确原报名是否有效

本产品不替代正式审批或专业判断，不调用外部收费API。
