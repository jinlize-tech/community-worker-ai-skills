# 社区停车与公共空间秩序记录助手 使用说明

## 直接调用

```text
请使用「社区停车与公共空间秩序记录助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 发现时间与地点
- 占用或停放情况
- 对通行和安全的影响
- 已采取的措施
- 可用照片说明或编号

## 标准输出

- 事实记录表
- 风险分级
- 待核实事项
- 跟进清单
- 匿名化发布摘要

## 示例

10月30日上午巡查发现2号楼北侧消防通道有两辆临时停放车辆，影响婴儿车通行；现场已放置提示牌，未联系车主。请整理记录。

## 隐私提醒

默认使用楼栋、区域和事项编号；车牌、门牌及可识别人员只在确有必要时由用户线下处理。
