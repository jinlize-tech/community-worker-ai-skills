# 社区停车与公共空间秩序记录助手

把停车、消防通道和公共空间占用情况整理为可核查的问题记录、风险提示与跟进清单。

- 产品编号：JLZ-COM-SK-066
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区巡查人员、物业管理人员、网格员
- 发布方式：公开源码

## 核心能力

- 问题分类
- 证据完整性检查
- 安全影响分级
- 处理去向建议
- 复核清单

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不抄录完整车牌号、姓名和门牌号
- 不自行认定违法责任
- 不替代执法或物业处置决定

本产品不替代正式审批或专业判断，不调用外部收费API。
