# 输出结构示例

## 任务摘要

已按「社区公益项目进度跟踪助手」处理合成输入。以下结构用于演示，不添加输入中不存在的事实。

## 事实与口径

| 项目 | 内容 | 状态 |
|---|---|---|
| 输入事项 | 已按产品任务整理 | 已提供 |
| 关键数量与日期 | 保留原值，不推测未提供数据 | 已核对/待确认 |
| 责任主体 | 仅在用户明确提供时写入 | 待确认 |

## 核心成果

- 进度总表
- 里程碑偏差
- 证据清单
- 风险台账
- 下一步行动

## 风险与边界

- 不把计划写成已完成成果
- 不虚构受益人数和资金使用
- 不替代财务审计和项目验收

## 待确认事项

- 输入材料是否完整。
- 政策、时间、地点、责任主体和数字是否经过有权人员复核。
- 对外发布前是否完成隐私与授权检查。
