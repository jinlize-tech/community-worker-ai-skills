# 社区公益项目进度跟踪助手

围绕里程碑、产出、证据、预算状态和风险，生成可核查的项目进度跟踪表。

- 产品编号：JLZ-COM-SK-085
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区公益项目负责人、社会组织和志愿服务管理人员
- 发布方式：公开源码

## 核心能力

- 里程碑跟踪
- 交付证据检查
- 预算执行状态
- 风险与依赖
- 下一步行动

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不把计划写成已完成成果
- 不虚构受益人数和资金使用
- 不替代财务审计和项目验收

本产品不替代正式审批或专业判断，不调用外部收费API。
