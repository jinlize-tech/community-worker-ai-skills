# 社区公益项目进度跟踪助手 使用说明

## 直接调用

```text
请使用「社区公益项目进度跟踪助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 项目目标和周期
- 里程碑计划
- 已完成活动与产出
- 预算使用（如有）
- 风险和下一步

## 标准输出

- 进度总表
- 里程碑偏差
- 证据清单
- 风险台账
- 下一步行动

## 示例

项目周期3个月，计划完成4场活动、服务120人次。目前完成2场、登记80人次，预算使用40%。下一次活动因场地冲突延期一周。请跟踪。

## 隐私提醒

受益对象只记录匿名汇总；项目案例需取得授权并去除敏感细节。
