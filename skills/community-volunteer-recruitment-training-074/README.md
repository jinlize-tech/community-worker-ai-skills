# 志愿者招募与岗前培训助手

把服务需求转化为岗位说明、招募文案、筛选问题、岗前培训议程和现场须知。

- 产品编号：JLZ-COM-SK-074
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：志愿服务负责人、社区社会组织工作人员
- 发布方式：公开源码

## 核心能力

- 岗位任务拆解
- 招募文案
- 报名信息最小化
- 岗前培训议程
- 服务边界清单

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不设置与岗位无关的歧视性条件
- 不收集身份证号和健康隐私
- 不承诺志愿服务证明或补贴除非已批准

本产品不替代正式审批或专业判断，不调用外部收费API。
