# 公共场地预约与使用登记助手 使用说明

## 直接调用

```text
请使用「公共场地预约与使用登记助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 申请主体
- 场地与用途
- 起止时间
- 人数与设备需求
- 联系人和安全责任

## 标准输出

- 预约登记表
- 冲突检查
- 使用确认单
- 现场检查清单
- 待确认事项

## 示例

夕阳红志愿队申请11月8日14:00-17:00使用社区活动室，预计30人，需要投影和20把椅子，联系人已留电话。请登记并检查。

## 隐私提醒

申请人只记录姓名或组织名称的必要部分，公开表单使用预约编号。
