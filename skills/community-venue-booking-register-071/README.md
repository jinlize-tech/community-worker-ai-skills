# 公共场地预约与使用登记助手

整理场地申请、时段冲突、设备需求、使用确认和归还检查，形成清晰的预约登记。

- 产品编号：JLZ-COM-SK-071
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区活动负责人、物业前台、公共空间管理人员
- 发布方式：公开源码

## 核心能力

- 申请信息校验
- 时段冲突检查
- 设备与安全需求
- 使用确认单
- 归还检查

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不擅自承诺场地可用
- 不收集与预约无关的个人资料
- 涉及收费、押金和审批时标记待确认

本产品不替代正式审批或专业判断，不调用外部收费API。
