# 老年助餐登记与配送排班助手

整理助餐登记、餐食需求、配送路线和送达确认，突出缺餐、地址不清及食品安全异常。

- 产品编号：JLZ-COM-SK-076
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：老年助餐点工作人员、社区为老服务人员、志愿者协调员
- 发布方式：公开源码

## 核心能力

- 订餐登记
- 配送路线分片
- 送达状态
- 饮食限制提示
- 异常跟进

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不提供医疗营养诊断
- 不公开老人姓名、完整住址和健康情况
- 未确认食品安全问题时只提示上报

本产品不替代正式审批或专业判断，不调用外部收费API。
