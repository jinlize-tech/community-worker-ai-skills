# 社区人物故事写作助手

基于授权采访和事实材料撰写社区人物故事，区分原话、事实材料与AI润色内容。

## 适用场景

- 志愿者年度人物报道
- 社区能人故事
- 公益人物专访

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得虚构人物经历、引语和荣誉
- 不得把润色语言冒充受访者原话
- 涉及未成年人、健康、家庭困难等必须取得适当授权
