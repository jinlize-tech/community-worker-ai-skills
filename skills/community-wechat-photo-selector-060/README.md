# 公众号图片筛选助手

检查用户提供的社区照片，识别构图、清晰度、重复和隐私问题，推荐封面与文章配图并说明理由。

## 适用场景

- 活动结束后从多张照片中选封面
- 优先挑选无隐私风险的配图
- 整理照片发送顺序

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

WorkBuddy ViewImage 已验证可读取照片；PNG和WEBP文件在本地测试集可正常解码。客户运行时的图片附件权限以后台为准，未看图时不得分析。

## 边界

- 未实际看到图片时不得声称进行过视觉分析
- 不得默认公开含可识别个人信息的照片
- 不得使用未授权图片
- 不得把模糊或无关图片夸大为合格封面
