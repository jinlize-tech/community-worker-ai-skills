# 居民就业服务登记与转介助手

整理求职意向、工作条件和转介记录，形成岗位匹配要点、缺项和后续跟进清单。

- 产品编号：JLZ-COM-SK-079
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区就业服务人员、社会工作者、居民服务窗口
- 发布方式：公开源码

## 核心能力

- 求职需求登记
- 岗位条件比对
- 技能与培训需求
- 转介记录
- 跟进提醒

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不保证录用
- 不作歧视性筛选
- 不收集与岗位无关的家庭和健康信息

本产品不替代正式审批或专业判断，不调用外部收费API。
