# 志愿服务时长统计助手

依据签到、岗位和核验记录计算志愿服务时长，标出缺卡、重复和待确认项。

- 产品编号：JLZ-COM-SK-073
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：志愿服务负责人、社区工作人员、志愿团队管理员
- 发布方式：公开源码

## 核心能力

- 签到签退核对
- 岗位时长汇总
- 缺卡识别
- 重复记录检查
- 服务证明摘要

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不虚增或以活动名义补造时长
- 不把审核通过写成平台自动认证
- 缺少签退时不自行填数

本产品不替代正式审批或专业判断，不调用外部收费API。
