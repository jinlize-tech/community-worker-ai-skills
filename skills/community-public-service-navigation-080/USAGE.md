# 居民公共服务办事导航助手 使用说明

## 直接调用

```text
请使用「居民公共服务办事导航助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 居民要办的事项
- 适用地区
- 官方指南或链接
- 居民已备材料
- 无障碍或代办需求

## 标准输出

- 事项摘要
- 材料与步骤
- 渠道对照
- 常见问题
- 来源与待确认

## 示例

居民要办居住登记，社区提供街道公开指南：需身份证、居住地址证明、照片1张，可在粤省事或街道窗口办理。请做导航。

## 隐私提醒

不在示例中保留证件号、住址和联系电话；办理材料仅列种类。
