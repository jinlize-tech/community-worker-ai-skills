# 居民公共服务办事导航助手

把居民办事事项转化为材料、渠道、地点、时间、常见问题和来源待核实清单。

- 产品编号：JLZ-COM-SK-080
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区窗口人员、居民服务热线人员、网格员
- 发布方式：公开源码

## 核心能力

- 事项识别
- 材料清单
- 线上/线下渠道
- 地址时间核验
- 无障碍与咨询提示

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不编造办事地址、电话、时间和材料
- 不承诺一次办成
- 官方信息缺失时只给核验路径

本产品不替代正式审批或专业判断，不调用外部收费API。
