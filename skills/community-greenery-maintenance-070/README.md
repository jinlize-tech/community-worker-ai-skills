# 社区绿化养护记录助手

整理修剪、浇水、补植、病虫害观察和养护跟进记录，形成可追溯的工作台账。

- 产品编号：JLZ-COM-SK-070
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区绿化负责人、物业养护人员、社区工作者
- 发布方式：公开源码

## 核心能力

- 养护事项记录
- 季节风险提示
- 病虫害观察分级
- 补植跟踪
- 下次养护提醒

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 未提供药剂标签和专业意见时不建议农药配比
- 不把病虫害观察写成专业诊断
- 不承诺植物成活率

本产品不替代正式审批或专业判断，不调用外部收费API。
