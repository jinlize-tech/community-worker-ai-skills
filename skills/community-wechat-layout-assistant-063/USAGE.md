# 公众号图文排版助手 使用说明

## 能做什么

优化公众号文章段落、标题层级、引用、图片位置和阅读节奏，输出可安全粘贴的排版结构。

## 适合场景

- 长文章阅读吃力
- 活动推文需要图文穿插
- 政策稿需要清晰层级

## 使用准备

准备任务目标、目标读者、原始材料、发布时间、渠道、事实来源和需保留原文。图片材料请使用合成、授权或已脱敏内容。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 输入示例

请把以下合成文章重排为公众号结构：社区11月5日开展消防演练，9点在广场集合，居民可自愿参加，现场有志愿者引导。活动遇雨另行通知。

## 使用步骤

1. 说明希望完成的成果和发布渠道。
2. 粘贴或上传已有材料。
3. 明确哪些信息不能改写。
4. 检查系统列出的待确认和授权事项。
5. 人工确认后进入实际发布流程。

## 边界

- 不得声称HTML在所有编辑器兼容
- 不得用排版改变原文含义
- 不得擅自增加图片或数据
