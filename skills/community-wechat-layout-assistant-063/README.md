# 公众号图文排版助手

优化公众号文章段落、标题层级、引用、图片位置和阅读节奏，输出可安全粘贴的排版结构。

## 适用场景

- 长文章阅读吃力
- 活动推文需要图文穿插
- 政策稿需要清晰层级

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得声称HTML在所有编辑器兼容
- 不得用排版改变原文含义
- 不得擅自增加图片或数据
