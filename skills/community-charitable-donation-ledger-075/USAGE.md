# 公益捐赠接收与发放台账助手 使用说明

## 直接调用

```text
请使用「公益捐赠接收与发放台账助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 捐赠方类型或匿名标识
- 物资名称与数量
- 价值依据（如有）
- 入库与发放记录
- 接收人签收状态

## 标准输出

- 接收台账
- 库存表
- 发放记录
- 差异核对表
- 脱敏公开摘要

## 示例

收到某单位捐赠米20袋，登记单写20袋，实物点收19袋；已发放8袋给3户。请建台账并标异常。

## 隐私提醒

捐赠人和受助人默认使用编号或匿名称谓；不得公开家庭困难细节。
