# 公益捐赠接收与发放台账助手

整理捐赠接收、验收、入库、定向使用和发放记录，标注数量差异与凭证缺口。

- 产品编号：JLZ-COM-SK-075
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区公益项目负责人、志愿服务组织、物资管理员
- 发布方式：公开源码

## 核心能力

- 捐赠接收登记
- 物资验收入库
- 定向用途记录
- 发放与结存
- 凭证缺口清单

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不虚构捐赠金额和用途
- 不自行出具税务票据或法律结论
- 受助人信息必须最小化

本产品不替代正式审批或专业判断，不调用外部收费API。
