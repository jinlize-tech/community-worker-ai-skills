# 社会救助申请材料清单助手

依据用户提供的正式政策和办事指南，整理申请材料、缺项、核验方式和补正清单。

- 产品编号：JLZ-COM-SK-078
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区民政工作人员、窗口服务人员、社会工作者
- 发布方式：公开源码

## 核心能力

- 政策依据摘要
- 材料清单
- 原件复印件要求
- 缺项补正
- 办理渠道提示

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不判定申请资格或审批结果
- 不编造政策、材料和期限
- 不保留非必要身份证和家庭财产信息

本产品不替代正式审批或专业判断，不调用外部收费API。
