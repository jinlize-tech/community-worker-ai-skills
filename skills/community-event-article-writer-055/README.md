# 社区活动推文助手

生成活动预告、报名推文、流程说明、注意事项和活动结束宣传内容，并区分计划与实况。

## 适用场景

- 活动开始前招募
- 发布报名信息
- 活动结束后整理亮点

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得把计划写成已经举办
- 不得虚构报名人数和活动亮点
- 不得承诺未确认的名额和礼品
