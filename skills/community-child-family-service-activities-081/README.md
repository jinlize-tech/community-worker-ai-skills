# 儿童与家庭服务活动清单助手

把儿童与家庭服务活动整理为适龄说明、报名条件、安全要点、隐私要求和物资清单。

- 产品编号：JLZ-COM-SK-081
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区儿童主任、亲子活动负责人、社会工作者
- 发布方式：公开源码

## 核心能力

- 活动适龄说明
- 家庭报名条件
- 安全与陪同要求
- 物资清单
- 儿童隐私检查

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不收集儿童身份证号和完整家庭情况
- 不承诺教育或治疗效果
- 复杂个案转介专业人员

本产品不替代正式审批或专业判断，不调用外部收费API。
