# 社区政策宣传文案助手

把正式政策文件转化为公众号文章、微信群通知、政策问答和海报文案，保留来源与有效性。

## 适用场景

- 发布居民办事政策宣传
- 微信群通知政策变化
- 制作社区公告栏政策问答

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得脱离原文扩大或缩小政策范围
- 不得虚构补贴金额、时限或资格
- 不得作出办理资格认定
- 必须提示以正式政策文本为准
