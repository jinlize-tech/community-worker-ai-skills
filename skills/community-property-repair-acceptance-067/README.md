# 物业维修验收与整改清单助手

依据用户提供的维修范围、合同要求和现场记录，形成验收要点、缺陷清单与整改复验安排。

- 产品编号：JLZ-COM-SK-067
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区物业协调人员、业委会成员、社区工作者
- 发布方式：公开源码

## 核心能力

- 验收项目拆解
- 缺陷分级
- 整改责任与期限表
- 复验清单
- 资料归档提示

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不替代施工、消防、电气等专业检测
- 不对隐蔽工程作合格判断
- 未提供合同或规范时不编造验收标准

本产品不替代正式审批或专业判断，不调用外部收费API。
