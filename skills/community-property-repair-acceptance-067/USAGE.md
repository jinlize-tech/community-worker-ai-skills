# 物业维修验收与整改清单助手 使用说明

## 直接调用

```text
请使用「物业维修验收与整改清单助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 维修事项与范围
- 约定标准或合同条款
- 现场完成情况
- 发现的缺陷
- 验收参与方

## 标准输出

- 验收依据摘要
- 逐项检查表
- 缺陷与整改表
- 复验清单
- 验收结论草稿

## 示例

小区3号楼楼道灯已更换12盏，物业称全部完成。现场发现2盏闪烁、一处开关面板松动；合同要求质保12个月。请出验收与整改清单。

## 隐私提醒

只记录设施、工单和不具名验收人员角色，不收集住户室内隐私信息。
