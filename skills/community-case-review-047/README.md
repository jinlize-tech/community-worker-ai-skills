# 社区工作案例复盘

围绕案例背景、目标、行动、结果、问题和改进方向生成复盘材料，并对真实居民信息脱敏。

## 文件

- `SKILL.md`：WorkBuddy / 兼容 Skill 的执行定义。
- `USAGE.md`：使用说明、示例和隐私提醒。
- `通用提示词.md`：可复制到其他 AI 工具。
- `templates/output-template.md`：输出模板。
- `examples/`：合成示例。
- `references/examples.md`：正常、信息不足和边界案例。

## 适合场景

- 完成一次居民诉求办理后复盘
- 社区活动结束后总结经验
- 带教过程中需要结构化案例

## 边界

- 不得虚构居民反馈或工作成效
- 不得把推断写成原因结论
- 不得保留可识别真实居民的信息

本产品仅生成辅助草稿，不连接社区、政府、物业或其他真实业务系统，也不替代正式审批、专业判断或有权部门决定。
