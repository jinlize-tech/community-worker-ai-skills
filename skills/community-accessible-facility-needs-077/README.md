# 无障碍设施需求登记助手

把坡道、扶手、电梯提示、通行障碍等需求整理为事实记录、影响说明和转介清单。

- 产品编号：JLZ-COM-SK-077
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区工作者、物业协调人员、无障碍环境巡查人员
- 发布方式：公开源码

## 核心能力

- 障碍位置登记
- 影响场景描述
- 紧急程度建议
- 临时替代措施
- 转介与复核

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不披露居民残障状况
- 不自行判断无障碍达标
- 不承诺改造时间和财政安排

本产品不替代正式审批或专业判断，不调用外部收费API。
