# 公众号封面设计助手

为公众号文章制定封面视觉方案、标题布局、配色、构图和多尺寸适配提示，不虚构官方尺寸。

## 适用场景

- 活动推文需要封面
- 人物专访封面设计
- 政策宣传封面方案

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

具备视觉读取和设计说明能力；默认不调用生成式收费图像API。需要实际图片时，仅使用当前环境明确提供的免费能力，否则输出可复制设计提示词。

## 边界

- 不得把未经核实的封面尺寸写成官方规范
- 不得虚构人物、标识或活动场景
- 具备生成能力前不得声称已经输出成品
