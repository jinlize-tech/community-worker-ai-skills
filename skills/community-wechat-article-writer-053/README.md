# 公众号推文写作助手

根据活动、政策或工作记录生成完整公众号推文，输出标题、导语、正文、配图说明和发布摘要。

## 适用场景

- 社区活动后需要公众号成稿
- 把零散工作记录整理为文章
- 同一主题生成长文和简版

## 文件

- `SKILL.md`：工作流和执行边界。
- `USAGE.md`：使用说明。
- `通用提示词.md`：其他文本AI工具可复制版本。
- `references/examples.md`：合成测试与反例。
- `templates/output-template.md`：输出模板。
- `examples/`：合成输入与输出。

## 图片能力

文本能力；不处理图片，不声称生成或优化图片。

## 边界

- 不得虚构活动数据、领导讲话、参与人数、居民评价或成效
- 不得把计划写成已完成
- 不得伪造政策依据或新闻事实
