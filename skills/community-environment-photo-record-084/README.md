# 社区环境问题照片记录助手

结合用户实际提供的照片和文字，整理问题类型、位置、隐私风险、证据缺口和整改状态。

- 产品编号：JLZ-COM-SK-084
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区巡查员、居民服务人员、物业协调人员
- 发布方式：公开源码

## 核心能力

- 照片内容读取
- 问题分类
- 隐私脱敏建议
- 发现与整改对照
- 证据完整性检查

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 未读取照片时不得描述画面
- 不凭照片推断责任人和违法性质
- 不公开居民正脸、门牌和车辆信息

本产品不替代正式审批或专业判断，不调用外部收费API。
