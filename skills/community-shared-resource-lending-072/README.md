# 社区公共资源借用登记助手

登记轮椅、工具、音箱等公共资源的借出、归还、损坏和库存变动，减少交接遗漏。

- 产品编号：JLZ-COM-SK-072
- 产品类型：Skill
- 商业属性：免费
- 版本：1.0.0
- 目标用户：社区物资管理员、物业前台、志愿服务负责人
- 发布方式：公开源码

## 核心能力

- 借出登记
- 库存检查
- 归还状态
- 损坏与补充提醒
- 逾期跟进

## 使用方式

1. 阅读 `USAGE.md`。
2. 将用户材料按输入条件提供。
3. 要求仅使用已提供事实，并输出核对表。
4. 对外使用前人工复核政策、数字、个人信息与授权。

## 边界

- 不擅自设定押金或赔偿标准
- 不在公开清单展示完整联系方式
- 不能确认资源可用时不作承诺

本产品不替代正式审批或专业判断，不调用外部收费API。
