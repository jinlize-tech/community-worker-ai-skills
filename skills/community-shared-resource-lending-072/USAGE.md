# 社区公共资源借用登记助手 使用说明

## 直接调用

```text
请使用「社区公共资源借用登记助手」处理以下材料。只使用我提供的事实，缺失信息标为待确认，并输出核对表：
[粘贴材料]
```

## 建议输入

- 资源名称与数量
- 借用人或组织
- 借出和预计归还时间
- 用途
- 交接状态

## 标准输出

- 借出台账
- 归还清单
- 库存提醒
- 逾期跟进
- 损坏记录

## 示例

志愿者队借出折叠桌2张、红色马甲10件、便携音箱1台，预计11月6日归还；音箱电池仓卡扣松动。请登记。

## 隐私提醒

借用人以内部编号或组织名记录；公开台账去除电话和身份证明信息。
