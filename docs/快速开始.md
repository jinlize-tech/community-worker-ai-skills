# 快速开始

## 在支持 Skill 规范的客户端

打开 `skills/<产品名>/`，查看 `USAGE.md`。如果客户端支持导入标准 `SKILL.md`，按客户端界面导入；如果不支持，使用同目录的 `通用提示词.md`。

## 在 WorkBuddy

打开 `docs/WorkBuddy使用指南.md`。正式市场上的 Skill 仍需通过 WorkBuddy 开放平台审核和用户授权后发布。

## 在其他 AI 工具

打开 `prompts/<产品名>.md`，复制提示词，再粘贴自己的业务材料。不要把提示词中的示例当成真实社区数据。

## 开始前

- 使用化名、事项编号和脱敏地点。
- 删除身份证号、完整门牌号、电话和不必要健康信息。
- 明确最终材料需要由社区工作人员核实。
