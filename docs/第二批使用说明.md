# 第二批使用说明

第二批包含15款免费 Skill，覆盖邻里沟通、宣传政策、居民议事、安全应急和社区工作者培训。

优先使用 `skills/<产品名>/SKILL.md`。不支持 Skill 的 AI 工具可使用 `prompts/<产品名>.md`。所有示例均为合成材料。

这些工具仅生成辅助草稿、记录、训练和核对材料。它们不连接政府、社区、物业或其他真实业务系统，不替代正式审批、执法、医疗诊断、专业安全检查、居民表决或有权部门决定。

不要向公开仓库、Issue、讨论区或未经批准的外部系统提交真实居民身份证号、完整住址、电话、健康病史或其他非必要个人信息。

WorkBuddy 后台实际分类、AI 标注、付费模式、平台解析和审核结果以平台当期页面为准。
