# Contributing

1. Use synthetic or fully de-identified examples only.
2. Do not submit real resident names, addresses, phone numbers, ID numbers, health data, family details, case records, credentials, or private community data.
3. Keep each Skill focused on one concrete workflow and document its input, output, missing-information behavior, and limits.
4. Do not add external paid API dependencies for the free basic workflow.
5. Do not copy third-party text, images, prompts, or policy material without clear authorization.
6. Changes to brand files are not accepted without written authorization from 广州金励泽科技服务有限公司.

By contributing original free content, you agree that it may be distributed under Apache-2.0, except brand assets and third-party materials.
