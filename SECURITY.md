# Security and Privacy

Do not open a public issue containing real resident data, personal information, credentials, API tokens, private screenshots, or internal case records.

For a security concern, use GitHub's private security advisory feature for this repository. If that is unavailable, report only a minimal, sanitized description and wait for a private reporting channel.

The project does not connect to government, community, property-management, healthcare, emergency, or payment systems. Never treat generated text as a verified official record.
