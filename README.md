## 直接使用

1. 免费Skill：进入 `skills/<机器标识>/`，阅读 `USAGE.md`。
2. 免费专家：进入 `agents/<机器标识>/`，按专家说明导入或使用。
3. 其他AI工具：使用 `prompts/` 或Skill目录中的通用提示词。
4. 付费产品：查看 `paid-skills/` 或 `paid-agents/` 中的基本信息；正式获取和使用以WorkBuddy平台为准。
